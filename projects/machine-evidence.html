Industrial recordings / compilation

Every value carries its origin.

  1. 01

    Preserve

    raw bytes + source identity

    Retain source recordings before protocol decoding or interpretation.

  2. 02

    Decode

    frames → canonical values

    Map fields, track sequence gaps, duplicates, reordering, resets and incomplete fragments.

  3. 03

    time basis + source authority

    run bundle + replay

    Package canonical records, quality summaries and provenance for repeatable analysis.

01 / Implementation

Source ingestion

  • Implemented file intake, raw recording storage and queued ingest/compile workflows.
  • Built source-pack and mapping contracts for robot context, scanners, controller diagnostics and reference measurements.
  • Built VDA 5050/MQTT and read-only OPC UA intake, SICK scan3 UDP datagram parsing and reassembly, picoScan REST capture, Flexi Soft gateway inputs, and MCAP/rosbag2 file ingestion.
02 / Implementation

Temporal integrity

  • Tracked sequence gaps, duplicate events, reordering, resets, incomplete fragments and stale data.
  • Preserved timing basis and alignment quality rather than treating every received timestamp as equivalent.
  • Retained source class, confidence, derivation and provenance alongside canonical observed values.
03 / Implementation

Compilation and replay

  • Compiled run bundles with canonical timelines, events, quality summaries and reference-channel assessments.
  • Separated raw recording from interpretation so an episode can be revisited as mappings evolve.
  • Built integrity/quarantine handling, stable export surfaces and operational reports for downstream analysis.
Engineering note

A value without its origin can be the wrong evidence.

A fleet report, a diagnostic channel and an independent physical measurement can all describe motion while supporting different conclusions. The compiler keeps the source semantics and transformation history attached to the value so downstream analysis can decide what the observation is sufficient to establish.
