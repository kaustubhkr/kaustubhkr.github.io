Overview

I built the pipeline around learning to drive from visual observations: collecting expert behaviour, predicting controls, and reusing learned features inside an interactive reinforcement-learning setup.

  • Built expert-data collection, visual imitation learning and continuous-control training paths.
  • Reused imitation-checkpoint features, fused with vehicle state, inside an actor–critic pipeline.
  • Implemented simulator environments, checkpoint recovery, monitoring and multi-environment training utilities.

01 / Implementation

Observation to control

  • Adapted the visual model to five input channels while retaining pretrained RGB weights for the first three.
  • Used separate steering, throttle and brake heads for the imitation path.
  • Built the CARLA environment interface and the observation/action plumbing for interactive training.
02 / Implementation

Representation reuse

  • Loaded the imitation checkpoint into a custom feature extractor and removed the final control-regression heads.
  • Combined the extracted visual representation with state inputs through a learned projection.
  • Integrated the extractor with Stable-Baselines3 SAC and separate policy/critic networks.
03 / Implementation

The experiment infrastructure

  • Implemented checkpoint discovery and resume logic, evaluation and monitoring utilities.
  • Added multi-environment training paths and tools for recovering interrupted experiments.
  • Kept collected demonstrations, imitation models and interactive-learning experiments in the same development trail.
Engineering note

Transfer the representation; inspect the control problem again.

A representation learned from expert examples supplies a useful starting point, but interactive training changes the observations the agent encounters. The pipeline makes the feature-transfer boundary explicit so the demonstration model, state inputs and actor–critic objective can be inspected separately.
