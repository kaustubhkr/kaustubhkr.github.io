01 / Implementation

Controller comparison & learned representation

  • Compared Model Predictive Contouring Control (MPCC) with modified PPO and SAC controllers in the same autonomous-racing project.
  • Built a multi-head attention encoder as part of the learned-control work.
  • Developed the controller variants and encoder in a private local codebase. The retained PPO baseline uses a separate, explicit observation/action contract.
02 / Implementation

The retained PPO baseline

  • Wrote the ROS 2 environment bridge around LiDAR, collision and lap feedback, with steering and throttle command publishers.
  • The retained baseline includes 180 LiDAR features and 25 discrete steering–throttle combinations, with lower-throttle turning actions and higher-throttle straight actions.
  • Maintained additional observation and factored-action experiments as the training interface evolved.
03 / Implementation

The training system

  • Experimented with collision penalties, survival terms, throttle incentives and lap feedback. The reward defines what the agent is encouraged to do; lap outcomes establish what it actually did.
  • Built checkpoint resume, evaluation and training variants around Stable-Baselines3 PPO.
  • The accompanying manuscript investigates compact LiDAR policies, observation aggregation and reward shaping. I am its first author; it is not published.
04 / Implementation

The inference continuation

  • In 2026, added ONNX export, TensorRT engine-build tooling and Triton serving adapters. These extensions came after the 2025 competition.
Engineering note

The control contract shapes the policy.

Compressing a scan changes which geometry the agent can observe. Discretising steering and throttle changes the manoeuvres it can express. Rewarding throttle commands changes the optimisation target without directly measuring speed. I treated these choices as part of the controller, alongside the network and optimiser.
