Overview

I independently built and submitted the reinforcement-learning racing controller. The entry placed third in qualification at the ICRA 2025 RoboRacer Sim Racing League, with an 81.32-second run, zero collisions, and an 8.03-second best lap.

  • Designed LiDAR observation contracts and coupled steering–throttle action spaces.
  • Built the ROS 2 ↔ Gymnasium training loop, reward experiments and checkpoint evaluation.
  • Extended the system with ONNX export, TensorRT build tooling and Triton serving adapters.

01 / Implementation

The agent–environment boundary

  • Wrote the ROS 2 environment bridge around LiDAR, collision and lap feedback, with steering and throttle command publishers.
  • Competition-era code includes 180 LiDAR features and 25 discrete steering–throttle combinations, with lower-throttle turning actions and higher-throttle straight actions.
  • Maintained additional observation and factored-action experiments as the training interface evolved.
02 / Implementation

The training system

  • Experimented with collision penalties, survival terms, throttle incentives and lap feedback. The reward defines what the agent is encouraged to do; lap outcomes establish what it actually did.
  • Built checkpoint resume, evaluation and training variants around Stable-Baselines3 PPO.
  • The accompanying manuscript investigates compact LiDAR policies, observation aggregation and reward shaping. I am its first author; it is not published.
03 / Implementation

The inference continuation

  • Added ONNX policy export, TensorRT engine-building tools, inference benchmarking utilities, and Triton configuration/client paths.
  • These are later extensions, added in 2026. The competition controller and the later inference tooling have separate histories.
Engineering note

The control contract shapes the policy.

Compressing a scan changes which geometry the agent can observe. Discretising steering and throttle changes the manoeuvres it can express. Rewarding throttle commands changes the optimisation target without directly measuring speed. I treated these choices as part of the controller, alongside the network and optimiser.

Project context

Simulation competition. Third in qualification; the entry later finished 14th in the final time-attack race. The two rounds evaluate different runs and tracks.
